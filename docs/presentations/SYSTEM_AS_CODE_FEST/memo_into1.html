08 What does architecture-as-code look like?

What does architecture-as-code look like?

The model is not just a diagram. It is source code for the safety argument.

SysML-style safety thread
package gpca.safety;

hazard HZ_001_Overdose {
  description = "patient receives excessive therapy";
}

riskControl RC_001_LockoutEnforcement {
  mitigates HZ_001_Overdose;
  allocatedTo SW_005_InfusionManager;
}

requirement REQ_025_IgnoreFrequentBolusRequest {
  satisfies RC_001_LockoutEnforcement;
}

verify VER_002_VerifyBolusLockout
  verifies REQ_025_IgnoreFrequentBolusRequest;

What the code gives us

  • Stable identifiers for review and release baselines.
  • Typed relationships instead of informal trace labels.
  • Diffable safety evidence through normal code workflows.
  • A model that can be checked by rules.
This is the bridge: model text becomes the source code of the safety argument.
