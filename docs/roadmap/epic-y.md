# Epic Y: Scenario Editor And Diff

Wave: 4 (UI thin wrapper)

Priority: P2

Goal: support scenario branches with element-link tooling and a visual diff renderer.

Depends on: Epic P (shell), Epic W (diff viewer).

## Stories

### Y-1 Scenario editor base

Session target: 30 minutes or less.

Acceptance: editor opens a scenario fixture.

### Y-2 Element-link tool inside scenarios

Session target: 30 minutes or less.

Acceptance: links resolve to canonical model elements.

### Y-3 Model diff core

Session target: 30 minutes or less.

Acceptance: diff core powers both CLI and UI.

### Y-4 Diff renderer (Tab 4)

Session target: 30 minutes or less.

Acceptance: diff renders inline per scenario.

## Epic Exit

- Scenarios coexist with the canonical model and diff cleanly.
