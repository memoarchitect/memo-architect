# MEMO EARS Snippets

This folder contains a VS Code snippet pack for EARS requirement authoring.

## Install

1. Open VS Code.
2. Run `Preferences: Configure User Snippets`.
3. Choose `sysml` (or `New Global Snippets file`).
4. Paste the contents of `memo-ears.code-snippets`.

## Snippet prefixes

- `ears-u` — Ubiquitous
- `ears-e` — Event-driven
- `ears-s` — State-driven
- `ears-o` — Optional-feature
- `ears-un` — Unwanted-behaviour
